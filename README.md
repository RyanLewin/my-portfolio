Welcome to the source code for my personal developer portfolio! This project showcases my expertise in modern web development, highlighting my ability to architect performant, responsive web applications using a modern JavaScript ecosystem. 

🔗 **Live Site:** [ryanlewingames.com](https://www.ryanlewingames.com)

## 🛠️ Tech Stack

* **Framework:** Next.js (React)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Deployment:** Cloudflare Workers (Automated via GitHub)

## ✨ Key Features

* **Component-Driven UI:** Architected with custom, reusable React components to ensure long-term scalability and maintainability.
* **Themes:** Dark or Light mode toggle in the heading bar to suite personal preferences
* **Type Safety:** Fully typed with TypeScript to catch errors at compile-time and improve developer experience.
* **Responsive Design:** Mobile-first styling utilizing Tailwind CSS utility classes for seamless viewing across all devices.
* **3rd Party Integrations::** Making use of radix-ui's Accordion and Toggle components for drop-downs and filters.
* **Automated Deployments:** Configured with continuous integration so that every push to the main branch automatically builds and deploys to Cloudflare edge networks.
